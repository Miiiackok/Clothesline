# Clothesline · 桌面晾衣绳

一个 macOS 小工具：屏幕右上角垂下一截麻绳，截图会自己飞上去被彩色小木夹夹住；别的照片、文件拖过去也能挂上；要用的时候直接从绳子上拖走、双击打开，或者共享给别人。

原生 Swift + AppKit，常驻菜单栏，没有 Dock 图标。

---

## 它长什么样

**收起时**：主显示器右上角、菜单栏正下方（离右边缘约 140pt），一截黄麻细绳从屏幕上方垂下来，末端是一个小绳结和几缕散开的纤维。平时只露这一小截，不挡任何东西，也不拦鼠标。

**掉下来时**：整根绳子往下掉，到底时弹一下、左右摆几下。绳子经过的地方，照片一张张被"啪"地夹上并晃动。

**照片**：拍立得样式。
- 相框按原图比例：长截图挂上去也是长的，宽图是横的，整张图完整显示不裁切。面积大致固定，最宽 120pt、最长 220pt（约 1/4 屏高），超出就整体等比缩小。
- 米白相纸，有纸纹，底部两角微微翘起带阴影。
- 照片表面有一道斜向的光泽，内边有压印阴影。
- 白边靠外侧手写拍下的日期和时间；长度超过宽度 2.1 倍的长图，右边白边加宽，日期竖着写在那里（从下往上）。
- 左右交错挂在绳子两侧，歪 16°–22°，像被重力拉着斜挂在夹子上。

**文件夹**：竖版牛皮纸档案袋。
- 封口盖、两颗纽扣绕着白棉线，纸浆里有深色纤维点。
- 正中歪着盖一个"文件夹"印章。

**单个文件**：比档案袋小一号的透明按扣文件袋。
- 隔着磨砂塑料能看到文件内容的缩略图（PDF / Word 第一页、表格……）；压缩包这类没有内容可看的，袋里是一页空白纸。
- 上方翻盖一颗按扣，袋边和按扣按类型着色，袋上贴一个类型小标签：

  | 类型 | 标签 | 颜色 |
  |---|---|---|
  | PDF | PDF | 红 |
  | Word / Pages / RTF | DOC / PAGES | 蓝 |
  | Excel / Numbers / CSV | XLS / NUMBERS / CSV | 绿 |
  | PPT / Keynote | PPT / KEY | 橙 |
  | 压缩包、磁盘映像 | ZIP / RAR / 7Z / DMG… | 紫 |
  | 音频 | MP3 / WAV… | 粉 |
  | 视频 | MOV / MP4… | 靛 |
  | 文本 | TXT / MD | 棕 |
  | 其他 | 扩展名大写（最多 5 个字符），没有扩展名就是 FILE | 深棕 |

- 档案袋和文件袋下方都手写文件名，太长时中间省略。

**夹子**：刷了彩漆的迷你木夹，有金属弹簧和高光。颜色从珊瑚红、薄荷绿、芥末黄、天蓝、粉、淡紫里随机挑一个，每张固定。

**丢失**：引用的原文件被删或被挪走时，档案袋 / 文件袋变灰并盖上红色"已丢失"印章（照片则在白边写红字），不会悄悄消失。

## 怎么用

### 让绳子掉下来 / 收回去

| 操作 | 结果 |
|---|---|
| 鼠标停在右上角那截绳子上约 0.2 秒 | 绳子掉下来 |
| 按住鼠标拖着文件经过那截绳子 | 立刻掉下来，松手放到绳子上就夹上 |
| 新截图出现 | 自动掉下来，截图飞上去 |
| 鼠标离开绳子区域 1.5 秒 | 收回成一小截 |
| 菜单栏 →「保持绳子展开」 | 一直挂着，不自动收回 |

### 挂上去

- **截图**：按 ⌘⇧3 / ⌘⇧4 正常截图。系统右下角的浮动缩略图消失、文件写到桌面后（约 5 秒），缩略图会从屏幕右下角沿弧线飞到绳子最上面，边飞边缩小、转到挂着的角度，落地后被夹住。桌面上的截图文件被收进应用自己的文件夹，桌面保持干净。
- **其他照片**（比如隔空投送收到的、"下载"里的）：从访达拖到绳子上。照片会被**搬进**应用自己的文件夹。
- **文件**：从访达拖到绳子上。文件**不会被搬动**，绳子只记住它的位置。

最新挂上的在最上面，卡片越长，下一张离它越远。挂满了用触控板或滚轮上下滚动。

### 用

| 操作 | 照片 | 文件 |
|---|---|---|
| 单击 | 快速预览（约 0.3 秒后弹出，用来和双击区分） | 快速预览 |
| 双击 | 用「预览」打开，可标注（点笔尖图标或 ⇧⌘A） | 用默认应用打开原文件 |
| 拖到别的应用 / 访达 | 对方收到照片，绳子上这张被取下 | 对方收到原文件，绳子上这张被取下，原文件不动 |
| 右键 → 用预览标注 / 打开 | 同双击 | 同双击 |
| 右键 → 共享… | 系统共享菜单：隔空投送、信息、邮件、已安装应用的共享扩展 | 同左，发出去的是原文件 |
| 右键 → 在访达中显示 | ✓ | ✓ |
| 右键 → 拷贝 | 可粘贴到微信等应用（写法与访达一致） | 同左 |
| 右键 → 从绳子上摘掉 | 照片进系统废纸篓（可找回） | 只摘掉，原文件不动 |

在「预览」里标注保存后，绳子上那张拍立得会自动刷新成标注后的样子。

### 菜单栏（回形针图标）

- **暂停自动夹截图**：暂停期间的截图留在桌面，不会补夹。
- **保持绳子展开**
- **开机自动启动**：需要打包成 `.app` 后才生效。
- **退出 Clothesline**

## 运行

需要 macOS 13+ 和 Xcode（Swift 5.9+）。

```bash
cd /Users/mi/Desktop/desktop_design
swift run Clothesline
```

第一次运行时，系统可能会询问是否允许访问桌面文件夹，选**允许**，否则监听不到截图（手动拖入仍然能用）。

截图保存位置读取系统设置（`com.apple.screencapture` 的 `location`），没设置过就是桌面。

退出：菜单栏回形针 →「退出 Clothesline」，或在终端按 Ctrl-C。

## 数据放在哪

`~/Library/Application Support/Clothesline/`

| 路径 | 内容 |
|---|---|
| `Images/` | 挂在绳子上的照片（以及取下后等待清理的照片） |
| `index.json` | 绳子上有哪些东西、顺序、类型、路径、挂上的时间 |
| `retired.json` | 已从绳子上取下、等待清理的照片及取下时间 |

取下的照片在**取下 24 小时后、下一次启动应用时**删除。

## 几个关键设计

**照片搬进来，文件只引用。** 截图和照片挂上去就是为了收拾桌面，所以搬进应用自己的文件夹；文件（文档、压缩包、文件夹）往往还在别处被用着，所以只记位置，双击、拖出、共享用的都是原文件。

**取下照片时文件原地不动，24 小时后再删。** 微信这类应用不是在松手那一刻读文件，而是稍后才读，甚至等用户按发送时才读，所以取下只记一笔，过一段时间再清理。清理时绝不会删掉仍挂在绳子上的路径。

**绳子面板大小固定，收起时对鼠标透明。** 面板贴在屏幕右侧（宽 380pt、高度与可用区域一致），收起时 `ignoresMouseEvents = true`，不挡下面的窗口。是否该掉下来由每 0.1 秒一次的鼠标位置轮询决定（不需要辅助功能权限），拖文件经过时用 `NSEvent.pressedMouseButtons` 判断。

**左右交错按"从最旧的数起"。** 新照片加在最上面时，已经挂着的照片不会换边。

**动画都是逐帧算出来的。**
- 绳子：`RopeGeometry`（顶点、长度、末端摆动、中段弯曲）。长度和末端摆动各是一个阻尼弹簧：掉下来时欠阻尼，到底弹一下、左右摆几下；收回时临界阻尼，干脆利落。
- 卡片：每张卡片是一个 `CALayer`，绕夹子支点做弹簧式衰减摆动；插入、删除、滚动时沿绳子平滑移位。
- 一个 60fps 定时器在有东西在动时才运行。

**截图飞入**：绳子面板本来就从屏幕顶到底贴着右侧，系统缩略图的位置就在面板里，所以不另开窗口：新卡片自己从右下角沿弧线飞到绳子最上面，边飞边缩小、转到挂着的角度，落地后被夹住晃一下。

## 项目结构

```
Package.swift                       Swift Package：ClotheslineCore（逻辑）+ Clothesline（界面）
Sources/ClotheslineCore/            无界面逻辑，全部有单元测试
  Item.swift                        ClotheslineItem、ItemKind（image / file）
  ClotheslineStore.swift            条目列表、照片搬入、文件引用、取下、延迟清理、持久化
  ScreenshotDetector.swift          判断截图（扩展属性 kMDItemIsScreenCapture 或文件名前缀）；截图目录
  ScreenshotWatcher.swift           监听截图目录，报告新截图（带重试）
  DirectoryMonitor.swift            监听目录变化（截图目录、「预览」保存标注），合并成一次回调
  FileBadge.swift                   文件类型 → 印章文字和颜色
Sources/Clothesline/                AppKit 界面
  main.swift / AppDelegate.swift    启动、组装各模块
  MenuBarController.swift           菜单栏回形针
  RopeWindowController.swift        绳子面板、鼠标轮询、掉下/收回
  RopeView.swift                    卡片布局、掉下/收回/晃动/飞入的逐帧动画
  RopeView+Interaction.swift        点击、双击、拖出、拖入、右键菜单、滚动
  Motion.swift                      阻尼弹簧、RopeGeometry（绳子形状）
  RopeLayer.swift                   麻绳纹理和末端绳结的绘制
  CardLayer.swift                   一张卡片的状态（左右、位置、摆动、飞行）
  CardArt.swift                     拍立得 / 牛皮纸档案袋 / 透明文件袋 / 彩色木夹 / 纸纹的绘制
  Layout.swift                      尺寸常量、面板位置
  Thumbnails.swift                  后台生成照片和文件内容缩略图，文件改过自动重新生成
  QuickLook.swift                   单击快速预览
Tests/ClotheslineCoreTests/         22 个单元测试
```

## 测试

```bash
swift test
```

22 个测试，覆盖：

- **存储**：照片搬入、文件引用、按类型分流、文件夹按引用处理、最新在前、重启后保持、重名处理、丢失检测、`onChange` 回调。
- **取下与清理**：取下后照片仍在原路径、24 小时后才删、重启后仍能清理、绝不删绳子上的照片。
- **截图识别**：中英文截图文件名、截图扩展属性、隐藏文件和非图片排除、截图目录。
- **截图监听**：报告新截图、忽略启动前已有的文件、忽略普通图片、每张只报告一次。
- **目录监听**：「预览」式的安全保存能被发现、连续变化合并成一次回调、目录不存在时报错。
- **类型印章**：各类型映射、文件夹（.app 这类包不算文件夹）、未知扩展名、无扩展名。

界面部分没有自动化测试，在真实屏幕上手动验证。调试时可以用 `CLOTHESLINE_ROOT` 换一个数据目录，不碰真实数据：

```bash
CLOTHESLINE_ROOT=/tmp/clothesline-test swift run Clothesline -keepRopeOpen YES
```

## 已知限制

- **不支持"文件承诺"式拖拽**：从「照片」应用、部分浏览器直接拖出的图片，如果拖拽里没有真实文件路径，挂不上去。从访达、桌面、"下载"拖没有问题。
- **「预览」标注没有马赛克**，打开后也不会自动弹出标记工具栏，需要手动点笔尖图标或按 ⇧⌘A。
- **截图有约 5 秒延迟**：系统浮动缩略图消失、文件真正写到桌面后才会飞上去。
- **只在主显示器**（带菜单栏的那块）显示。
- **开机自动启动**需要先打包成 `.app`。
- 取下的照片只在**启动应用时**清理；应用长时间不重启时，取下的照片会在 `Images/` 里多留一阵。
